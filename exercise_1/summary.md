# The AI Engineering Skills Map: Parts 1–5
**By Andrew Ng — DeepLearning.AI**

### Part 1: The Essential Skills of an AI Engineer

AI is changing how we build software, and developers need to learn how to work effectively with AI tools. Andrew Ng highlights four essential skills: building AI applications, understanding software engineering, using coding agents, and knowing what products to build. The main lesson is that developers need more than coding skills; they must also understand problems and create solutions that are useful to people.

### Part 2: Building and Deploying AI Applications

Building AI applications requires more than connecting an AI model to software. Developers need to understand how LLMs work, connect them to reliable data, build AI agents, test their outputs, and maintain them in production. Since AI can make mistakes, developers must continually evaluate results and improve their systems. Machine learning knowledge also helps them make better technical decisions.

### Part 3: Software Engineering Fundamentals

AI tools can write code, but developers still need to understand how software works. Important skills include building full-stack applications, managing databases, designing system architectures, testing, security, and deployment. Without this knowledge, developers may accept poor technical decisions from AI. Understanding the fundamentals helps them build software that is secure, reliable, and easier to maintain.

### Part 4: Using Coding Agents Effectively

Coding agents can help developers plan, write, test, and deploy software, but their output is not always correct. To use them effectively, developers need to give clear instructions, provide the right context, review their work, and test the results. They must also know when to let an agent work independently and when human supervision is necessary. The goal is to use AI to work faster without sacrificing quality.

### Part 5: Shaping the Build

AI engineers should not simply build whatever they are told to build. They should help identify problems, understand users' needs, choose useful features, and decide what to develop next. This requires product thinking, communication, leadership, and taking responsibility for results. Instead of waiting for instructions, good engineers take initiative, test ideas, learn from feedback, and focus on creating real value.

## Overall Conclusion

The five articles show that becoming a good AI engineer involves much more than knowing how to code or use AI tools. It requires strong software engineering skills, an understanding of AI, the ability to guide coding agents, and the judgment to decide what is worth building. Most importantly, developers must keep learning and improving as technology changes.
