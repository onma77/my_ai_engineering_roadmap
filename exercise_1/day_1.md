# linear algebra intuition
# vector 
is simply a list of numbers.
for example 

```py

number = [3,2]
print(number)

```
- you move 3 steps to the right.(horizontal)
- you move 2 steps upward.(vertical)

- you acn also think of vector as a way of representing something using numbers.

# matrix
is a table of numbers arranged in rows and columns.

for example:

```py
matrix = [
    [1, 2]
    [3, 4]
]
print(matrix)
```

- matrix can be used to transform a vector.

# how AI uses matrices
neural network uses matrices to transform numerical inputs into outputs. for example, a network might recieve numerical representations of words and transform them as it processes a sentence.
